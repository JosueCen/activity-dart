# Compilado de ejercicios en Dart

Este repositorio contiene una serie de ejercicios desarrollados en **Dart** como parte de la pre-capacitacion para el puesto aspiracional de **desarrollador Front-End Jr**. Su finalidad es reforzar los conocimientos basicos del lenguaje, la programacion orientada a objetos y algunas caracteristicas propias de Dart.

## Contenido del repositorio

| Archivo o actividad | Tema | Descripcion |
|---|---|---|
| `Actividad_01` | Variables y tipos de datos | Se crean variables que representan informacion basica de una receta y se imprime la informacion en consola. |
| `Actividad_02` | Funciones | Se implementan tres funciones: saludar, determinar si una receta es express y calcular porciones. |
| `Actividad_03` | Listas | Se crea una lista de ingredientes y se prueban los metodos `.add()` para anadir ingredientes y `.remove()` para eliminar elementos. Los resultados se comprueban en consola. |
| `Actividad_04` | Mapas | Se define un mapa que representa ingredientes y sus porciones. Se practican operaciones para amadir y actualizar elementos, asi como verificar si un ingrediente existe. |
| `Actividad_05` | Clases y objetos | Se crea un objeto llamado `Recipe` y una funcion para imprimirlo en consola. |
| `Actividad_06` | Programacion orientada a objetos (POO) | Se incorpora la clase `Ingredient` y se crea una instancia para mostrarla en consola. |
| `Actividad_07` | Null safety | Se modifican los objetos para incluir propiedades opcionales y se establecen valores predeterminados para evitar valores `null`. |
| `Actividad_08` | `Future`, `async` y `await` | Se crea una funcion de tipo `Future` que simula la carga de informacion externa y muestra dos recetas en consola despues de dos segundos. |
| `Actividad_09` | Manejo de errores | Se utilizan `try` y `catch` en una funcion que busca una receta y muestra un mensaje de error. |
| `main` | Modelos de datos | Se simula la carga de informacion desde una API para transformarla en objetos `Recipe` e `Ingredient`. |
| `models` | Carpeta con los modelos | Se utiliza para el archivo `main` con el fin de simular una separación de resposabilidades. |

## Objetivo

Practicar conceptos fundamentales de Dart mediante ejercicios pequenos y progresivos, utilizando ejemplos relacionados con recetas e ingredientes.

## Tecnologias

- **Dart**
- Conceptos basicos de programacion y programacion orientada a objetos
